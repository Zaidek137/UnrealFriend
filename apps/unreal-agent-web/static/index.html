How To Use This Tool

Use this as the control panel for Unreal actions, strict Blueprint analysis, and debugging traces.

  1. In Unreal, keep your project open with the Unreal Agent plugin enabled, then click Health to confirm connection.
  2. Set Unreal Base URL to your bridge (default http://127.0.0.1:47777/unreal-agent/v1) and click Save.
  3. In Chat, type natural requests like “Create BP_EnemyScout, add BeginPlay print, compile.”
  4. Use Dry Run=true to preview planned actions without mutating assets.
  5. If mutations are blocked, click Approve & Retry to continue safely.
  6. Use Debug Traces to inspect failures quickly. Filter by terms like run-plan, ANALYSIS_CONTRADICTION, or compile_blueprint.
  7. Use List Recipes and Release Metrics to verify deterministic coverage and current pass-rate progress.
  8. When analysis is requested, trust the deterministic result + evidence links over free-form model guesses.
