What your Unreal Friend can do

This tool is built for agent-first Unreal development. It can create, wire, analyze, validate, and refactor gameplay systems with deterministic execution paths and safety gates.

Open Agent Chat View Live Capability API View Control Surfaces

Blueprint Node And Graph Authoring

Create variables, functions, macros, custom events, branches, and pin wiring. Authoring is exposed through deterministic operations so agents can build full graph workflows with less manual cleanup.

Native Unreal Asset Authoring

Build and edit Behavior Trees, Blackboard data, EQS queries, AnimBlueprint scaffolds, Materials, Niagara systems, and Level Sequences through direct editor actions.

UMG And UI Generation

Generate widget trees from templates, apply style presets, and bind events for interaction flows. Includes widget lint checks so agents can detect missing roots, unbound controls, and layout issues.

World And Scene Direction

Generate layouts and scatter assets with deterministic seeds, constraints, tags, and cleanup tokens. This supports fast scene iteration while keeping reversible generation cycles.

AI And Behavior Automation

Generate AI scaffolds, evolve blackboard schemas, and run scenario validation for AI goals. The system supports plan-driven behavior authoring and verification for autonomous gameplay logic.

Multiplayer Correctness By Default

Run replication lint, authority-guard insertion workflows, and multi-client PIE checks. Agents can gate changes against multiplayer safety rules before treating a run as production-ready.

Refactor, Explain, And Project Intelligence

Use refactor catalog/preview/apply, node-level explain routes, dependency graphs, hotspot scoring, and change impact analysis to keep large projects understandable and stable during automation.

Closed-Loop Autonomous Validation

Mutation flows can auto-run compile, contradiction checks, PIE scenario suites, replay determinism checks, performance/risk lint, and optional rollback handling when validation gates fail.

Agent Interfaces

The same control surface is available through Web API, CLI, and MCP tools. This allows agent runtimes in different environments to execute the same deterministic workflows without UI-only dependencies.

Commercial And Session Logging Backbone

Includes entitlement checks, usage events, paid session lifecycle endpoints, major-update stream logs, and exportable diagnostics for user-facing web products.
